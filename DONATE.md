## Before you send

- ⚠️ **Match the network to the address.** TRC20 funds sent to the Solana address (or vice versa) are unrecoverable. Copy the address directly from this page — don't retype it.
- Your wallet's own "Receive" screen will generate a QR code for either address if scanning is easier than copy-pasting.
- Sending a small test amount first is always reasonable if you're donating a larger amount.
